# このファイルについて
これはこのプロジェクトで実装される「ガイスター」というゲームのルールについてまとめたマークダウンである。
基本的なルールは一般に知れ渡っているゲームと同じとなっている。

# 概要
ガイスターとは、2人のプレイヤが6行6列の盤面で駒を交互に動かし、ゴールに辿りつかせることを目指す**2人零和不完全情報ゲーム**である。

動かす駒は「良いおばけ」（以下青駒と表記）と「悪いおばけ」（以下赤駒と表記）がそれぞれ4つずつ用意されており、相手プレイヤにはその正体が隠されている。
青駒は相手ゴールに辿りつかせると勝利になるが、全ての青駒を取られると負けてしまう。逆に赤駒はゴールに辿り着いても勝利とならないが、全ての赤駒を相手に取らせることで勝利となる。

駒の動きから相手駒の正体を推察すること、相手に自分の駒を誤認させることが肝のゲームとなっている。

# ゲームの準備
- 盤面は6行×6列（計36マス）のグリッドを使用する。
- 相手側の最も奥の行の左右両端のマスに隣接する盤外には「脱出口」が存在する。
- 各プレイヤは「青駒」4個、「赤駒」4個の計8個の駒を持つ。
- ゲーム開始時、各プレイヤは自分の手前の中央寄りの2行4列（計8マス）に、自分の駒8個を任意の組み合わせで配置する。配置した駒の色（正体）は相手からは見えないようにする。

# ゲームの進行
プレイヤは交互に自分の手番を行い、以下のルールに従って駒を動かす。
- **移動**: 自分の手番では、必ず自分の駒を1つ選び、前後左右（縦横）のいずれかに1マスだけ移動させなければならない。斜め方向には移動できない。
- **相手の駒を取る**: 移動先のマスに相手の駒がある場合、その駒を取る（盤面から取り除く）ことができる。取られた駒は盤外に置かれ、その時点で初めて色が相手に公開される。
- **制約**: 自分の駒がすでにあるマスには移動できない。パス（駒を動かさないこと）はできない。

# 勝利条件
以下の3つの条件のうち、いずれか1つを先に満たしたプレイヤが勝利となる。

1. **相手の良いおばけ（青駒）を全て取る**
   相手の青駒4個をすべて捕獲する。
2. **自分の悪いおばけ（赤駒）を全て取らせる**
   自分の赤駒4個をすべて相手に捕獲させる。
3. **自分の良いおばけ（青駒）を脱出させる**
   自分の青駒を、相手陣の角（奥の行の左右両端のマス）から盤外へ一歩移動させ、脱出させる。
   ※ 脱出できるのは青駒のみである。脱出口のマスに到達した次の手番で、盤外へ向かって移動させることで脱出が完了し勝利となる。
