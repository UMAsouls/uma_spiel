# このファイルについて
gatで使われるガイスタークライアントアプリ用モードの仕様をまとめたmd

# 仕組みの概要
1, 自分(AI)側の手番を決める
2, action_result_inputをTrueにして環境作成
3, 初期盤面生成、環境に入力
4, 初期盤面をサーバーに送信
5, サーバーから盤面を受け取る
6, 相手の行動を盤面変化から推測して環境に入力
7, AIによる行動選択
8, 行動結果を受け取る(駒を取ったかどうか)
9, 行動と行動結果を環境に入力
10, 6~9を繰り返す

# 初期盤面生成について
普段はお互いに1駒ずつ置いていく形だが、サーバー側の仕様として一気に置かないといけない
そこで初期盤面生成が指示されたら初期盤面を作り終わるまでこちら側でイテレーションを回す
相手側盤面はランダムにセットする
AIが入力した情報を変換・保存しておき、最後にサーバー側に合わせた形で送信する

# action_result_inputモードについて
action入力の9,10bitの領域に行動結果も入力することでその行動結果を反映させるモード
単純に取った駒が赤駒か青駒かを判定する処理を分岐させる
何もなし：0
赤を取った：1
青を取った：2

# 勝敗判定
相手側の行動で勝利が決まった瞬間、サーバー側から処理を要求されることは無くなるからその後は想定しなくていい

# 合法手生成について
合法手は青と赤で変わることが無いので変更なし
青駒のみ脱出処理があるが、相手側が勝利したら処理をせずに終了すればいいので考慮しない
