# このファイルについて
ガイスターの行動履歴の保存方法、そしてtensorへの出力方法を記載する

#　行動履歴の構造
## struct GeisterActionRecord
- int action -- 実際の行動
- bool got_pawn -- 駒を取ったか
- bool is_pawn_red -- 取った駒は赤であるか

## Tensor上での構造
- [位置x, 位置y, 種類z] = -0.5なら種類zの駒が位置(x,y)から移動した事を意味する
- [位置x, 位置y, 種類z] = -0.25なら種類zの駒が位置(x,y)へ移動し、赤駒を取った事を意味する
- [位置x, 位置y, 種類z] = 0.5なら種類zの駒が位置(x,y)へ移動したことを意味する
- [位置x, 位置y, 種類z] = 1.0なら種類zの駒が位置(x,y)へ移動し、青駒を取った事を意味する
- 20手の履歴tensorのシェイプ：(6,6,40)
