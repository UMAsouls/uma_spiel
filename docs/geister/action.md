# このファイルについて

ガイスターの実装で扱う行動の実装方法についてまとめてある

# 概要
今回の実装においてはガイスターの行動空間は(6,6,4)の3次元配列で表す。
Action(=int)型はその3次元配列を1次元にしたときのindexを表す。
また、policyや合法手もその形を利用して表す。

# Action

## 形式

- 0から(6×6×4-1)までの数で表される。
- その意味は6×6×4の3次元配列のどこの位置を表しているかで決まる
- 1、2軸は位置を、3軸目は動く方向を示す
    - ↑：0、↓：1、→：2、←：3
    - 例えば(x,y)の位置にある駒が上に行くというアクション：(x,y,0)= x + y×6 + 0×6×6
- 合計8bit使用

# 合法手

## 形式

- 6×6×4の3次元tensor A
- 合法手：true、非合法手：false
- 1、2軸は位置を、3軸目は動く方向を示す
    - ↑：0、↓：1、→：2、←：3
    - 例えば(x,y)の位置にある駒が上に行くことができるとき、A[x,y,0]＝true

# 行動方策

## 形式

- 6×6×4の3次元tensor A
- 値は確率を示す（0~1）
- データの意味は合法手と同じ
    - 例えば(x,y)の位置にある駒が上に行く確率が0.1なら、A[x,y,0]＝0.1
- ネットワークが出したlogitに合法手マスク（非合法手が-∞になる）をかけ、softmax
