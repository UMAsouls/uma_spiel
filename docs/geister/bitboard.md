# 概要

盤面を64bit整数で管理し、高速に合法手生成と勝敗判定を回すためのクラス

# クラス分け

## OnePlayerBoardクラス

- 一方のプレイヤ側の駒を管理する
- 青駒・赤駒の場所がそれぞれの変数に保存される
    - 64bitの下36桁を用いる
    - 最も下の桁が左上のマス
    - 1が存在、0が不在
- 駒の数による勝敗判定ができる
    - 赤駒の数が0なら勝ち
    - 青駒の数が0なら負け
- 駒が相手側の脱出口にいるかどうか判定できる
    - 青駒が脱出口にいるならtrue
- void move(fromx, fromy, tox, toy, player)
    - playerの盤上位置(fromx, fromy)の駒を(tox, toy)に移動させる
- void erase(x,y,player)
    - playerの(x,y)の駒を削除
    - すなわち、(x,y)の位置の値を0にする
- long long getMultiBoard(bool reverse=false)
    - 赤駒と青駒の位置を記した64bit整数を返す
        - 駒の区別はしなくていい
        - or演算で作れる
    - reverse=trueなら相手から見た盤面を返す
        - 論理演算とか用いて高速に実装したい
        - 最悪、反転boardを予め用意して連動させるのもいいかも

## GeisterStateクラス

- 2プレイヤ分のOnePlayerBoardインスタンスを持つ
- 合法手生成を担当する
    - getMultiBoardで手番プレイヤの駒位置取得
    - 手番プレイヤのBoardを全て移動方向にシフト
        - 例えば左方向に動くなら右1シフト
        - 上下左右で結果を4つ作る
    - それらを手番プレイヤのものとand演算
    - そうすることで移動先に自分の駒があるか分かる
- 相手側脱出口に青駒がいる場合は、その駒を上方向に移動させる手のみを合法手として返す
  - 相手側脱出口の位置を1としたマスクを作成し、それとand演算した値を上方向合法手の位置に保存
- vector<vector<int>> getIntBoard()
    - 盤面を二次元配列で取得する
- string getStringBoard()
    - 盤面を文字列形式で取得する
- void PrintBoard()
    - 盤面を標準出力する
    - getStringBoard()をそのまま出力

# 盤面データの文字列

以下の方式

|0||1|2|3|4|5|6|
|---|---|---|---|---|---|---|---|
|1||#|o|o|o|o|#|
|2||#|o|o|o|o|#|
|3||#|#|#|#|#|#|
|4||#|#|#|#|#|#|
|5||#|r|r|r|r|#|
|6||#|b|b|b|b|#|

- o：敵の駒
- r：自分の赤駒
- b：自分の青駒
